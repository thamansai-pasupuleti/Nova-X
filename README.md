# NOVA X — Technology Product Website

A simple promotional webpage for a fictional gaming laptop brand called **NOVA X**. It was created as a first-year Web Development activity using **HTML5 and CSS3**.

## About the project

The webpage presents a concept gaming laptop and gives visitors a quick overview of its features, specifications, and sample price.

## Sections

- Product introduction
- Main features
- Product design
- Specifications
- Sample customer review
- Price and call-to-action section

## Technologies used

- HTML5 — webpage structure and content
- CSS3 — layout, colors, spacing, and responsive styling

## Files

- `index.html` — main webpage
- `style.css` — styles used by the webpage

## Run locally

1. Download or clone this repository.
2. Keep `index.html` and `style.css` in the same folder.
3. Open `index.html` in a web browser. You can also use the Live Server extension in Visual Studio Code.

## Deployment

This project can be hosted free using GitHub Pages:

1. Upload both files to the root of a GitHub repository.
2. Open **Settings → Pages**.
3. Select **Deploy from a branch**, choose `main` and `/(root)`, then save.
4. Open the published URL shown on the Pages settings screen.

## Note

NOVA X is a fictional concept brand. Product details, specifications, and price shown on the page are illustrative and do not represent a real product.
